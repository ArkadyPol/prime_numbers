# Rust Primes Project 🦀🔢

Изучение концепций однопоточности и многопоточности в Rust на примере различных алгоритмов поиска простых чисел.
Проект демонстрирует эволюцию оптимизации: от базового перебора делителей до продвинутого сегментированного решета с побитовым сжатием данных.

## Архитектура проекта (Cargo Workspace)

Проект организован в виде единого рабочего пространства Cargo и разделен на 10 независимых крейтов:

- **`main`** — Точка входа. Управляет запуском итераторов, валидацией данных и бенчмаркингом.
- **`prime_single_thread`** — Базовый алгоритм: простой перебор делителей в один поток.
- **`simple_multi_thread`** — Перебор делителей в несколько потоков с использованием `thread::scope` и разделением буфера результатов через `chunks_mut`.
- **`channel_multi_thread`** — Перебор делителей с передачей найденных чисел через многопоточный канал `std::sync::mpsc::channel`.
- **`arc_multi_thread`** — Перебор делителей с безопасным разделением Read-Only контекста через `Arc::new` и сбором через `handle.join()`.
- **`sieve_single_thread`** — Классическая реализация решета Эратосфена в одном потоке.
- **`sieve_multi_thread`** — Параллельное решето Эратосфена с использованием `thread::scope` и `chunks_mut`.
- **`bit_sieve_multi_thread`** — Решето Эратосфена с побитовым сжатием (1 бит на число) для экономии кэша процессора, многопоточность через `iter_mut`.
- **`segmented_single_thread`** — Сегментированное решето Эратосфена в одном потоке (оптимизация под размер кэша L1/L2).
- **`segmented_multi_thread`** — Параллельное сегментированное решето Эратосфена. Самый быстрый, масштабируемый и продвинутый вариант.
- **`atkin_single_thread`** — Решето Аткина в одном потоке. В теории самый быстрый вариант, но на практике сталкивающийся со сложными вычислениями.

## Результаты бенчмаркинга

### 🔹 1 000 000 простых чисел

_(Последнее число: `15 485 863`)_

- `prime_single_thread` — **~683 мс**

### 🔹 10 000 000 простых чисел

_(Последнее число: `179 424 673`)_

| Алгоритм               | Время выполнения | Примечание                                         |
| :--------------------- | :--------------- | :------------------------------------------------- |
| `prime_single_thread`  | **~18.4 с**      | Базовый однопоток                                  |
| `simple_multi_thread`  | **~2.7 с**       | `thread::scope` + `chunks_mut`                     |
| `channel_multi_thread` | **~2.7 с**       | `thread::scope` + каналы (`mpsc`)                  |
| `arc_multi_thread`     | **~2.72 с**      | Оптимизированный `Arc` (без клонирования в циклах) |
| `sieve_single_thread`  | **~233 мс**      | Смена алгоритма: мгновенный отрыв                  |

### 🔹 100 000 000 простых чисел

| Алгоритм                     | Время выполнения | Особенности                                               |

| `sieve_single_thread`        | **~3.2 с**       | Ограничен скоростью работы с RAM                          |
| `sieve_multi_thread`         | **~2.0 с**       | Параллельная обработка                                    |

| `bit_sieve_multi_thread`     | **~1.6 с**       | Битовая упаковка снижает нагрузку на шину памяти          |
